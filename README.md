# 株式会社クロノキャスト HP（静的サイト）

`chrono-cast.com` の公開情報をもとに作成した、1ページ構成のコーポレートサイトです。  
レイアウトは `kk-generation.com` のトップページ構成（セクション配置）を参考にしています。

## 主なセクション

- 固定ヘッダー
- ヒーロー
- 主な支援領域帯
- 当社のサービス
- Why ChronoCast?
- 私たちについて
- 主な支援テーマ
- 採用CTA
- お知らせ
- お問い合わせフォーム（ダミー送信）
- 会社情報フッター

## ファイル構成

- `index.html` : ページ本体
- `styles.css` : デザイン
- `script.js` : メニュー開閉・年表示・スクロール連動UI・フォーム送信表示

## ローカルでの確認方法

以下のコマンドを実行し、ブラウザで `http://localhost:8000` を開いてください。

```bash
python3 -m http.server 8000
```
