# AI開発会社ホームページ（サンプル）

AI開発会社「株式会社オーロラAI」を想定した、静的コーポレートサイトです。  
シンプルで見やすい構成にしています。

## 含まれるセクション

- ヒーロー
- 私たちについて
- サービス
- 対応技術
- 導入の流れ
- 導入事例
- よくある質問
- 会社情報
- お問い合わせフォーム（ダミー）
- スマホ向けメニュー

## ファイル構成

- `index.html` : ページ本体
- `styles.css` : デザイン
- `script.js` : メニュー開閉・年表示

## ローカルでの確認方法

以下のコマンドを実行し、ブラウザで `http://localhost:8080` を開いてください。

```bash
python3 -m http.server 8080
```
