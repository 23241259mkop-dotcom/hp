# 株式会社クロノキャスト HP（静的サイト）

`chrono-cast.com` の公開情報をもとに、株式会社クロノキャスト向けの
1ページ構成コーポレートサイトを静的ファイルで作成したサンプルです。

## 主なセクション

- ヒーロー（タグライン）
- 私たちについて
- 事業内容（3領域）
- Mission / Vision / Value
- 採用情報
- 会社情報
- お問い合わせフォーム（ダミー送信）

## ファイル構成

- `index.html` : ページ本体
- `styles.css` : デザイン
- `script.js` : メニュー開閉・年表示・スクロール連動UI・フォーム送信表示

## ローカルでの確認方法

以下のコマンドを実行し、ブラウザで `http://localhost:8000` を開いてください。

```bash
python3 -m http.server 8000
```
