# 企業ホームページ（サンプル）

シンプルなコーポレートサイトを静的ファイルで作成したサンプルです。  
以下の要素を含みます。

- ヒーローセクション
- 私たちについて
- 事業内容
- 導入実績
- 会社情報
- ニュース
- お問い合わせフォーム（ダミー）
- スマホ向けモバイルメニュー

## ファイル構成

- `index.html` : ページ本体
- `styles.css` : デザイン
- `script.js` : メニュー開閉・年表示

## ローカルでの確認方法

以下のコマンドを実行し、ブラウザで `http://localhost:8000` を開いてください。

```bash
python3 -m http.server 8000
```
