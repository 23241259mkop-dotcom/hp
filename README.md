# AI開発会社ホームページ（サンプル）

AI開発会社「株式会社Aurora AI」を想定した、静的コーポレートサイトのサンプルです。  
以下の要素を含みます。

- ヒーローセクション（実績・対応領域）
- 私たちについて
- AI開発サービス
- 開発プロセス
- 導入事例
- 会社情報
- ニュース
- お問い合わせフォーム（ダミー）
- スマホ向けモバイルメニュー

## ファイル構成

- `index.html` : ページ本体
- `styles.css` : デザイン
- `script.js` : メニュー開閉・年表示

## ローカルでの確認方法

以下のコマンドを実行し、ブラウザで `http://localhost:8000` を開いてください。

```bash
python3 -m http.server 8000
```
