# AI開発会社ホームページ（サンプル）

AI開発会社「株式会社オーロラAI」を想定した、静的コーポレートサイトのサンプルです。  
以下の要素を含みます。

- ヒーローセクション（実績表示）
- 私たちについて
- サービス紹介
- 対応領域
- 導入の流れ
- 導入事例
- 会社情報
- お問い合わせフォーム（ダミー）
- スマホ向けモバイルメニュー
- スクロール時の表示アニメーション

## ファイル構成

- `index.html` : ページ本体
- `styles.css` : デザイン
- `script.js` : メニュー開閉・年表示・表示アニメーション

## ローカルでの確認方法

以下のコマンドを実行し、ブラウザで `http://localhost:8080` を開いてください。

```bash
python3 -m http.server 8080
```
