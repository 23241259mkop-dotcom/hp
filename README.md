# 企業ホームページ（サンプル）

シンプルなコーポレートサイトを静的ファイルで作成したサンプルです。  
以下の要素を含みます。

- ヒーローセクション
- 私たちについて
- 事業内容
- 導入実績
- 会社情報
- 採用情報
- ニュース
- お問い合わせフォーム（ダミー送信メッセージ表示）
- スマホ向けモバイルメニュー
- スクロール連動ナビゲーション表示
- ページ上部へ戻るボタン

## ファイル構成

- `index.html` : ページ本体
- `styles.css` : デザイン
- `script.js` : メニュー開閉・年表示・スクロール連動UI

## ローカルでの確認方法

以下のコマンドを実行し、ブラウザで `http://localhost:8000` を開いてください。

```bash
python3 -m http.server 8000
```
