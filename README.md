# 企業HP（静的サイトテンプレート）

このリポジトリには、依存なしでそのまま公開できる **企業向けトップページ**（HTML/CSS/JS）を含みます。

## 起動方法（ローカル確認）

`/workspace` で下記を実行し、ブラウザで `http://localhost:8000` を開いてください。

```bash
python3 -m http.server 8000
```

## 主なファイル

- `index.html`: トップページ本体
- `assets/styles.css`: デザイン（ライト/ダーク、レスポンシブ）
- `assets/main.js`: メニュー、テーマ切替、年号更新、問い合わせフォームの mailto 生成
- `assets/logo.svg`: ロゴ（サンプル）

## カスタマイズ手順（最低限）

- **社名/説明文**: `index.html` の `title` / `meta description` / ヘッダーの「株式会社サンプル」を置換
- **連絡先**: `index.html` の `info@example.com` を実アドレスに置換
- **問い合わせフォーム送信先**: `assets/main.js` の `to = "info@example.com"` を置換
- **会社情報**: `index.html` の会社概要（所在地/設立/事業内容）を実情報に置換
- **実績/お知らせ**: ダミー文面を差し替え

## 注意

- 問い合わせフォームは **サーバー送信を行わず**、メール作成画面（`mailto:`）を開く方式です。
- 実運用のプライバシーポリシーは、法務確認のうえ内容を更新してください。
